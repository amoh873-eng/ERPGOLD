# تقارير التدقيق والإصلاح المحاسبي (Accounting Audit & Repair Reports)

تقارير مرجعية لمراحل تدقيق/إصلاح النواة المحاسبية. أُدرجت هنا لتكون جزءًا من المصدر
المُصدَّر (المستودع)، مع إبقاء أدلة التشغيل الخام (سجلات/لقطات) محليًا خارج المستودع.

| التقرير | المرحلة/الموضوع |
|---|---|
| `ERP-CORE-ACCOUNTING-GAP-ASSESSMENT.md` | تقييم الفجوات الأولى لنواة المحاسبة (P0) |
| `ERP-CORE-ACCOUNTING-FIX-REPORT.md` | تقرير الإصلاحات الأولى + فحوص الانحدار |
| `ERP-CORE-ACCOUNTING-BALANCE-RECONCILIATION.md` | مطابقة الأرصدة الرقابية/المساعدة + العيوب المؤكدة |
| `ERP-CORE-ACCOUNTING-END-TO-END-REPORT.md` | الاختبار الشامل من الطرف للطرف + مراجعة القرارات F‑A…F‑E |
| `ERP-CORE-ACCOUNTING-INTEGRITY-REPORT.md` | فحوص السلامة الداخلية للدفاتر والمخزون |
| **`ERP-CORE-ACCOUNTING-P7-REPAIR-REPORT.md`** | **P7: إصلاح G1 (مسار الأرصدة الافتتاحية للمخزون) و G2 (ارتداد الشيك/حالة الفاتورة/أعمار الذمم) + فحوص P7 (8/8) + الحزمة الكاملة (79/79) + اختبار متصفح حقيقي (10/10)** |

## ملاحظات

- لا تحتوي هذه التقارير على أي أسرار أو بيانات عملاء أو اتصالات قواعد بيانات — كل الأرقام من قواعد اختبار معزولة.
- أدلة التشغيل التفصيلية (سجلات الاختبارات، لقطات الشاشة، السكربتات) تُدار محليًا في مجلد `_p7/` في بيئة التطوير وليست جزءًا من المستودع؛ التقرير يوثّق مواقعها ومجاميعها.
- بصمة P7 والتحقق: انظر §12 في `ERP-CORE-ACCOUNTING-P7-REPAIR-REPORT.md`.
